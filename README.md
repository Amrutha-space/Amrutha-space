# I Engineer : 
Build software that solves real problems—not just projects that sit in a GitHub repository. Whether it's engineering scalable backend systems, crafting full-stack applications, or experimenting with AI-powered solutions, I'm driven by one question: **"Can this be built better?"**<br><br>Curiosity is probably my strongest skill. It leads me to explore new technologies, break things, fix them, and keep improving until they feel right. I'm a little chaotic when I'm building—my tabs multiply, whiteboards fill up with ideas, and side experiments somehow become full-fledged projects—but that's where my best work usually begins.<br><br>I enjoy working with **Java, Spring Boot, Python, JavaScript, React, Node.js, Express.js, SQL, Docker, Git, REST APIs, cloud deployments, and AI integrations**, with a strong interest in backend engineering, distributed systems, and scalable software design.<br><br>For me, coding isn't just about writing features—it's about understanding problems, designing thoughtful solutions, and constantly learning. Every project is another opportunity to build something faster, cleaner, and more meaningful than the last.<br>
